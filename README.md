# Kuromi AI

Aplikasi chat AI dengan sistem login dan landing page, dibangun dengan React + Vite.

## Fitur

- **Halaman Login** — Form login dengan typing effect, animasi orbs, dan tombol submit
- **Landing Page** — Halaman setelah login dengan hero, fitur cards, CTA, dan footer
- **Chatbox** — Ruang percakapan dengan AI, riwayat memori, dan typing indicator
- **Animasi** — Menggunakan anime.js v4 untuk reveal, floating, dan pulse effects

## Tech Stack

- React 19
- Vite 8
- anime.js 4
- Bootstrap Icons

## Memulai

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
